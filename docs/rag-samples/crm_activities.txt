CRM Activities — Communication Log
=====================================
Activities track every interaction with a contact or deal.

FIELDS:
- type: Kind of activity (Call, Email, Meeting, Task, Note) — color-coded enum
- notes: Description of what was discussed or done (not shown in the grid)
- scheduled_at: Date and time of the activity
- done: Boolean — true = completed (green), false = pending (red)
- deal_id: Deal this activity relates to (dropdown showing the deal title)
- contact_id: Contact involved (dropdown showing the contact's last name)
- created_at: Set automatically, read-only

ACTIVITY TYPES (with their grid colors):
- Call: Phone or video call (blue)
- Email: Email sent or received (green)
- Meeting: In-person or virtual meeting (yellow)
- Task: Action item or follow-up to complete (purple)
- Note: Free-text memo, no external action (grey)

HOW TO USE:
- Log activities after every client interaction
- Set done = false for future scheduled actions (they appear on the Calendar)
- Set done = true when completed
- Activities also show as a subtable on both the parent deal and the parent contact

CALENDAR:
Activities with a scheduled_at date appear on the Calendar in blue, titled by their type
with the notes as subtitle, and a notification fires 1 day before scheduled_at.
Clicking an activity in the calendar opens edit.php?table=activities&id={id}

FILTERING:
- Filter by deal_id to see all communications for one opportunity
- Filter by done = false to see open tasks and upcoming actions
- Filter by type to isolate calls, meetings or emails

DASHBOARD:
- "Activities Status" pie chart shows done vs pending
- "Activities Over Time" area chart counts activities per week by created_at

PRINT:
Menu → Activity Agenda renders activities newest-first with the related deal and contact,
filterable by type or completion. See the CRM Reports and Printouts doc.
