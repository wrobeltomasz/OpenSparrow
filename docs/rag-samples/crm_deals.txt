CRM Deals — Sales Pipeline
===========================
A Deal represents a sales opportunity with a specific company and contact.

FIELDS:
- title: Name of the deal (e.g. "Enterprise License Q2"), required
- value: Estimated revenue in currency units
- stage: Current pipeline position (color-coded enum)
- expected_close: Target closing date
- company_id: Linked company (dropdown showing the company name)
- contact_id: Primary contact person (dropdown showing first and last name)
- created_at: Set automatically, read-only

DEAL STAGES (in order, with their grid colors):
1. Lead — Initial interest, not yet qualified (grey)
2. Qualified — Confirmed need and budget (blue)
3. Proposal — A proposal has been prepared/sent (yellow)
4. Negotiation — Terms being finalized (yellow)
5. Won — Deal closed successfully (green)
6. Lost — Deal did not proceed (red)

ROW HIGHLIGHTING IN THE GRID:
On top of the per-stage cell colors, whole rows of the Deals grid are colored by value:
150,000 and above turns green, below 40,000 turns red, anything between stays plain.
Rules are evaluated in order and the first match wins, so the color reflects value
regardless of stage.

ATTACHMENTS (image gallery):
Deals have a record image gallery labelled "Attachments", up to 5 per record, with a
thumbnail column in the grid. The demo seeds seven document images: a signed contract
scan and an approved terms sheet on "Enterprise License Q2", a solution architecture and
a rollout plan on "Digital Transformation Project", a source system inventory on "Cloud
Migration Services", a signed order form on "Support & Maintenance" and a site photo on
"Cloud Infrastructure Buildout". This is separate from Menu → Files, which holds ordinary
file attachments (see crm_collaboration.txt).

OTHER STAKEHOLDERS (many-to-many):
Besides the single primary contact_id, a deal can list any number of extra contacts in
the "Other Stakeholders" field on its edit page. This is a many-to-many link stored in
the deal_contacts junction table, with an optional role per link.

HOW TO PROGRESS A DEAL:
- Change stage in the grid or the edit form, or drag its card between lanes on the
  Deals Board — dragging updates deals.stage exactly like editing the field
- Log activities (calls, meetings, emails) to track communication

DEALS BOARD (Kanban):
Menu → Deals Board shows one lane per stage (Lead, Qualified, Proposal, Negotiation,
Won, Lost). Each card shows the deal title plus its company, value and expected close
date. Dragging a card to another lane moves the deal to that stage.

AUTOMATIONS ON DEALS:
- "Deal Won — Close Notification": when a deal is updated and its stage becomes Won, the
  user who made the change gets an in-app notification linking back to the deal.

RELATED RECORDS (subtables on a deal's edit page):
- Activities: type, scheduled at, done, notes

PIPELINE SUMMARY VIEW:
Menu → Pipeline Summary gives deal and activity measures per company and stage: contact
count, deal count, total/average/max/min deal value, deal value standard deviation, first
and last expected close date, overdue deals (expected close in the past while the deal is
neither Won nor Lost) and activity totals (all / done / open, average per deal). Rows are
grouped by stage with per-group aggregates, and drill-down is enabled. Color rules
highlight more than 3 contacts (red), total value over 300,000 (green) and more than one
overdue deal (red).

DASHBOARD:
- "Deals by Stage" bar chart
- "Pipeline Value" stat card — sum of value across all deals that are neither Won nor Lost
- "Deals Value Over Time" area chart — deal value summed per month by created_at

CALENDAR:
Deals appear on the calendar by expected_close date (yellow, 3 days advance warning).
Clicking one opens edit.php?table=deals&id={id}

PRINT:
Menu → Pipeline Report renders open and closed deals with company, contact, value and
expected close date, filterable by stage or company. See the CRM Reports and Printouts doc.

FILES:
Deals are a file-relation target — documents can be attached and browsed from Menu → Files.
